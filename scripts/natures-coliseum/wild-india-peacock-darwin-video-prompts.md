# WILD INDIA (PEACOCK) — Video Prompts

10 seconds per beat · image-to-video · every prompt standalone · each beat has a plain Description and a Stability line to stop the animals morphing · each beat continues from the one before (see Continuity)

## Using these prompts in Grok Imagine
1. Upload the beat's image, choose the **custom prompt** option, and paste the **Grok Prompt**. It puts the motion first, because Grok reads the prompt from left to right.
2. Grok mostly **ignores negative prompts**. That's why the Grok Prompt turns every "don't" into a positive instruction: exactly how many animals are in the frame, and that the background stays still and solid.
3. Make **6-second clips** at **720p**. To fill a 10-second beat, use Grok's **extend** option on the last frame instead of one long clip. Long clips are where backgrounds melt.
4. Keep the motion small. If a clip still adds animals or melts, regenerate it once. If it keeps failing, regenerate the **image** first, then animate again.
5. Make a quick 480p test first to check the motion, then the final at 720p.

## Settings for other video tools
1. Paste the **Short Video Prompt** first. The image already sets the look, so the video prompt only needs to describe the motion. Long prompts make tools add extra animals.
2. Put the **Negative Prompt** in your tool's negative-prompt box, if it has one.
3. Set **motion strength / motion amount low** (around 3–5 out of 10) and the camera to **static or slow**.
4. Generate **5-second clips** and use two per 10-second beat. Long clips are where backgrounds start to melt.
5. If your tool supports it, use the same image as both the **first and last frame**, so the scene can't drift.
6. If a beat still fails, regenerate the **image** first with the Negative Prompt, then animate it again.
